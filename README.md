# সনাতন বিদ্যাপীঠ — Web App (v1.0 ডেমো)

চালু আছে: **http://<sandbox>:8000** (ব্রাউজারে লাইভ প্রিভিউ দেখুন)

## ফাইল কাঠামো
```
app/
├── index.html               # শেল (view + tabbar + toast/fx)
├── manifest.webmanifest     # PWA মেটাডেটা
├── css/
│   └── app.css              # ডিজাইন টোকেন + সব কম্পোনেন্ট/স্ক্রিন
└── js/
    ├── gita.js              # শ্রীমদ্ভগবদ্গীতা — ৭০১ শ্লোক (বাংলা লিপি + দেবনাগরী), যাচাই করা
    ├── gita-bn.js           # গীতার বাংলা অনুবাদ ও সহজ ভাষ্য (৭০১ শ্লোক সম্পূর্ণ)
    ├── data.js              # কনটেন্ট ডেটা (গ্রন্থ, শ্লোক, কুইজ, পূজা, পঞ্জিকা, সেবা, প্রোভাইডার)
    └── app.js               # রাউটার + স্টেট + স্ক্রিন + ইন্টারঅ্যাকশন
```
কোনো বিল্ড স্টেপ নেই, কোনো বাইরের লাইব্রেরি নেই — শুধু `python3 -m http.server` বা যেকোনো স্ট্যাটিক হোস্টে চলে।

## কাজ করা ফিচার (ডেমোতে সত্যিই চলে)
| স্ক্রিন | কার্যকারিতা |
|---|---|
| **হোম** | সময়-অনুযায়ী সম্ভাষণ, আজকের তিথি/নক্ষত্র/শুভ সময় (গণনা), স্ট্রিক রিং, **আজকের সাধনা চেকলিস্ট** (সেভ হয়), চলমান পাঠ, আসন্ন উৎসব, সেবা ব্যান্ড |
| **লাইব্রেরি** | সার্চ (লাইভ ফিল্টার), ক্যাটাগরি চিপ, গ্রন্থ/শ্লোক/অডিও সেগমেন্ট (empty state), **গীতা অধ্যায়-ম্যাপ ১৮ ঘর** (অগ্রগতি অনুযায়ী) |
| **পাঠ-ভিউয়ার** | সংস্কৃত + বাংলা + সহজ অর্থ, **ফন্ট সাইজ সেভ**, বুকমার্ক, "পাঠ সম্পন্ন" → অগ্রগতি ও স্ট্রিক আপডেট |
| **কোর্স** | ৩ কোর্স, সিলেবাস টাইমলাইন, লেসন ✓ (সেভ), অগ্রগতির রিং |
| **পরীক্ষা** | পরবর্তী শুক্রবারের **লাইভ কাউন্টডাউন**, লিডারবোর্ডে আপনার সেরা স্কোর, আগের ফলাফল |
| **কুইজ ইঞ্জিন** | ১০ প্রশ্ন, **টাইমার (অটো-সাবমিট)**, উত্তর সংরক্ষণ, স্কোর + প্রতিটি প্রশ্নের ব্যাখ্যা, রিট্রাই |
| **পূজা গাইড** | ধাপে ধাপে চেকলিস্ট (দিন-ভিত্তিক সেভ), মন্ত্র, **উচ্চারণ শুনুন** (Speech Synthesis) |
| **পঞ্জিকা** | **বাংলা (বঙ্গাব্দ) ও ইংরেজি — দুই ভিউ টগল**; বাংলা মাস-গ্রিডে বড় করে বাংলা তারিখ, ছোট করে ইংরেজি তারিখ; মাস আগে/পরে সরানো, তিথি-নক্ষত্রের গণনা, **একাদশী ও আজ হাইলাইট**, দিন-ট্যাপে বিবরণ (বাংলা তারিখ + ঋতু), ব্রত-তালিকা |
| **সেবা** | ক্যাম্পেইন প্রগ্রেস, **দান (সিমুলেটেড) → রিসিট সংরক্ষণ**, ৯৩%/৭% স্বচ্ছতা ব্রেকডাউন |
| **মার্কেটপ্লেস** | সার্চ + ক্যাটাগরি, ভেরিফায়েড প্রোভাইডার, **বুকিং (এসক্রো সিমুলেশন)**, "প্রোফাইল খুলুন" → নিজেই তালিকায় যুক্ত |
| **আমার** | সাপ্তাহিক সাধনা চার্ট (আসল লগ থেকে), আয়-হিসাব (৮৫/১২%), সেটিংস: **ডার্ক/পাটা-লাইট, ঘণ্টাধ্বনি, অ্যানিমেশন, নাম, রিসেট** |
| **দৈনিক হিসাব (Tracker)** | ৪ স্তম্ভ — **আধ্যাত্মিক** (পূজা/জপ/ধ্যান/পাঠ/দান মিনিট), **চরিত্র** (মিথ্যা ও ক্রোধের সংখ্যা), **কর্ম** (কাজের সময়, আয়, শেখা), **জীবন** (পরিবার, ঘুম, যোগা) · অ্যাপের ডেটা **অটো-যোগ** · দৈনিক স্কোর, ১৪ দিনের হিস্ট্রি, মাস্টারমাইন্ড ইনসাইট |
| **সাধনা** | **জপ কাউন্টার** (১০৮-এর মালা রিং, মন্ত্র বাছাই, হ্যাপটিক+ঘণ্টা, সেভ), **ধ্যান টাইমার** (৫/১০/১৫/২০ মিনিট, ৪-৪-৮ শ্বাস-নির্দেশ, সেশন লগ), **যোগা** (৮ আসন + সূর্য নমস্কার ১২ ধাপের গাইডেড প্লেয়ার) |
| **ভূমিকা (Role)** | ৫টি রোল: শিক্ষার্থী · অভিভাবক · শিক্ষক · পর্যালোচক · অ্যাডমিন — বদলালে স্ক্রিন ও অনুমতি বদলায় |
| **ম্যানেজমেন্ট (অ্যাডমিন)** | ব্যবহারকারী তালিকা (সার্চ, অনুমোদন, স্থগিত), **ভেরিফিকেশন কিউ**, **মডারেশন কিউ**, **পেআউট (দ্বৈত অনুমোদন ০/২→২/২)**, **অডিট লগ** |

| **শিক্ষক প্যানেল** | শিক্ষার্থী তালিকা, কোর্স, মাসিক আয় |

## ডিজাইন
- **ডার্ক মোড (ডিফল্ট):** মেরুন-গোল্ড, প্রদীপের শিখা, ভাসমান বোকেহ, ফিল্ম গ্রেইন।
- **লাইট মোড:** আপনার দেওয়া ছবির **ক্রিম + সিঁদুর লাল পাটা-বর্ডার**।
- টাইপ স্কেল, ৮pt স্পেসিং, স্টেট (hover/active/disabled/focus-visible), `prefers-reduced-motion` সম্মান।

## ডেটা কোথায় থাকে
`localStorage`-এ (`svp_*` কী)। স্যান্ডবক্স/প্রাইভেট মোডে না পেলে মেমরিতে চলে — অ্যাপ ভাঙে না।
রিসেট: **আমি → ডেমো ডেটা রিসেট**।

## বাস্তব প্ল্যাটফর্মে যাওয়ার পরের ধাপ
1. **ব্যাকএন্ড:** Supabase (Postgres + Auth OTP + Storage) — `00-MASTER-GUIDE.md`-এর স্কিমা অনুযায়ী।
2. **পেমেন্ট:** bKash/Nagad + SSLCommerz, এসক্রো ও দ্বিমুখী লেজার।
3. **কনটেন্ট:** শাস্ত্রীয় পর্যালোচনা বোর্ড → API থেকে বই/শ্লোক সিঙ্ক।
4. **রিয়েল পঞ্জিকা API** (এখন গণনা-ভিত্তিক নমুনা ডেটা)। বাংলা তারিখ বাংলাদেশের **২০১৯ সংশোধিত পঞ্জিকা** (বৈশাখ–আশ্বিন ৩১ দিন, ফাল্গুন ২৯/৩০, ১ বৈশাখ = ১৪ এপ্রিল) অনুসারে গাণিতিকভাবে হিসাব হয়; তিথি/নক্ষত্র/শুভসময় এখন নমুনা — প্রকাশের আগে সত্যিকারের পঞ্জিকা সূত্র দিয়ে প্রতিস্থাপন করা দরকার।
5. **PWA অফলাইন ক্যাশ** (service worker) + Play Store (Capacitor)।

> ডেমো পঞ্জিকা ও কিছু কনটেন্ট নমুনা — প্রকাশের আগে শাস্ত্রীয় পর্যালোচনা বাধ্যতামূলক।
